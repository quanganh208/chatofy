# Review and delegation

Use direct execution for a small bounded change. Use an independent tester/reviewer context
for cross-module, public-contract, security or data risk, following repository review
requirements and user delegation preferences. Where delegation is unavailable, review
inline and do not report it as a completed independent review.

Research and planning delegates are optional when uncertainty or coordination warrants them.
Parallel workers need disjoint files and known integration points. Finalization can reconcile
plan files and docs inline; no Engineer-only skill is required in a core-only installation.
Explicit `--advice` uses its own supervisor checkpoints.
