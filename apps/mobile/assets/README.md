# assets/

Placeholder 1×1 transparent PNGs are checked in so `expo start` boots without errors.

**Replace before building for distribution:**

| File                | Required size     | Purpose                          |
| ------------------- | ----------------- | -------------------------------- |
| `icon.png`          | 1024×1024         | App icon (iOS + Android)         |
| `splash.png`        | 1284×2778 (or 2×) | Splash screen image              |
| `adaptive-icon.png` | 1024×1024         | Android adaptive icon foreground |
| `favicon.png`       | 48×48             | Web favicon                      |

Use the Expo docs on [app icons and splash screens](https://docs.expo.dev/develop/user-interface/splash-screen-and-app-icon/) for exact specs.
