Chatofy — visual direction

Rough shapes, not finished screens. This exists to answer one question before ~4 days of work starts: is this the right direction? Every colour, size and space below is an existing token — nothing new is invented. What is being proposed is where things sit and what dominates.

1. The core move: the translation becomes the largest thing on screen

Today the page title is 24px and the translation is 22px — the heading outranks the content. That single inversion is most of why the surface reads like a test rig: nothing on it claims to be the point.

What this does not claim

These are shapes and weights, not final screens — spacing will move, copy will be rewritten against the register table, and the overlay is not mocked here at all (it lives in a closed shadow root over live video, so it can only be judged on a real call, at Phase 6). The one thing to react to now is the hierarchy: translation first and largest, controls quiet, one action per surface. If that reads wrong, saying so now costs an hour instead of four days.
