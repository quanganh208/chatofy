### Key findings:

1. **Vietnamese number vocabulary** is well-isolated in repair-number-vocabulary.ts and vietnamese-number-grammar.ts; used for ITN and repair validation; all marked structural or hardcode with measured justification
2. **English number vocabulary** mirrors Vietnamese in repair-number-vocabulary.ts; separate tier structure for en_to_vi repair path
3. **Translation prompts** (buildTranslationInstruction) contain ~2000-char hardcoded instruction with specific language rules (Vietnamese "ai" handling, speaker POV, identifier spelling); measured against live API
4. **Summarization prompts** (buildMinutesInstruction) contain ~1200-char hardcoded JSON instruction; same prompt-injection boundary as translator
5. **Glossary/hotword caps** are tripled: 48 hotwords/glossary pairs hardcoded at sidecar, socket, and prompt builder level (intentional redundancy: three independent trust boundaries)
6. **Punctuation model** (dewpoint.py) has 44 caseless-language codes and 10 no-space-language codes; script-specific punctuation marks; character-stripping regex
7. **Text normalization** uses 4 regex patterns for Unicode normalization (invisible chars, controls, combining marks, Vietnamese tone normalization)
8. **Model lists** (DEFAULT_MODELS): hardcoded fallback model IDs for Gemini translation and summarization
