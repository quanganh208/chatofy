## 2. Recorder Lifecycle — Records Straight Through Pause

**File:** `/home/quanganh208/Documents/QuangAnh/chatofy/apps/web/src/hooks/use-conversation-recording.ts`

- **attach()** (line 125): Creates `MediaRecorder`, stores `startedAtMs = Date.now()`, calls `recorder.start()`; passed to `openMicrophone()`
- **finish()** (line 192): Calls `recorder.stop()` if state !== 'inactive', returns collected blob + `durationMs`
- **startedAtMs** (line 63): Stamped even if recorder fails; published to live transcript via state

**Critical comment** (lines 98-105):

```
## Why it records straight through pause

`ConversationSession.pause()` releases nothing (it stops no tracks), so the stream stays live
and this keeps writing. That is deliberate: a paused recorder makes media time diverge from
wall-clock time, and every offset after the first pause would be wrong by the accumulated
pause length. The cost is real and the landing copy has to carry it — a person who believes
pause silences the microphone would be mistaken.
```

**Key insight:** MediaRecorder is NOT called with `.pause()`/`.resume()` — it records continuously. Pause affects only what the pump consumes (audio stops flowing to server), not what's recorded locally.

## 3. Turn Offsets: Clock Sources & Computation

**File:** `/home/quanganh208/Documents/QuangAnh/chatofy/apps/web/src/lib/transcript-time.ts`

- **mediaOffset()** (line 66): `Math.max(0, offsetMs - (audioOffsetMs ?? 0))` — converts conversation time to recording time
  - Used for BOTH live display and history playback seek
  - `offsetMs`: ms from `startedAt` (conversation wall-clock)
  - `audioOffsetMs`: ms from `startedAt` to first recorded sample (recorder-relative)

- **recordingOffsetMs()** (line 82): Computes the shift from conversation start to recording start
  - Parses `startedAt` (ISO-8601 from `Date.now()` at conversation open)
  - Subtracts from `recordingStartedAtMs` (epoch ms when recorder attached)
  - Clamped to `[0, MAX_DURATION_MS]`

- **offsetMs clock sources:**
  - Live: Generated by client reducer as turn.offsetMs (ms from conversation start when turn opened)
  - Stored: `ConversationTurn.offsetMs` nullable int, in ms from conversation start
  - Recording: Stored as `Conversation.audioOffsetMs` nullable int
