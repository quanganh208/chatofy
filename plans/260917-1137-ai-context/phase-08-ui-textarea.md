# Phase 8: @chatofy/ui — textarea via shadcn

## Goal

Add the one primitive the description field needs, generated by the shadcn CLI
and re-skinned, because `packages/ui/src/react/` has `input.tsx` and no
`textarea.tsx` and hand-writing one is forbidden.

## Files to Create / Modify

- Create: `packages/ui/src/react/textarea.tsx` (generated)
- Modify: `packages/ui/src/react/index.ts`

## Tasks & Steps

1. From `packages/ui`, run `npx shadcn@latest add textarea`. The aliases in
   `packages/ui/components.json` put it at `src/react/textarea.tsx`
   (`"ui": "@/react"`).
2. Re-skin it to this project's tokens, the same mechanical pass every sibling
   went through — `skin-guard.spec.ts` is what holds that in place after the
   fact, and its own header explains why the pass is invisible to `tsc` and to
   the eye.
3. **Do not quote a complete forbidden utility class in the file's comments.**
   Tailwind scans this package's source for anything shaped like a class and
   generates what it finds, comments included — five dead rules were shipped this
   way once (`skin-guard.spec.ts:19-29`). Describe the offender; do not spell it.
4. Export `Textarea` from `packages/ui/src/react/index.ts`, in the shadcn
   primitives block, alphabetically after `Tabs`.
5. Rebuild the package. **Then restart the web dev server if one is running** —
   a `packages/ui` rebuild replaces `dist` under a running Next dev server and
   the stylesheet it had resolved goes stale. Measure the running server, not a
   local compile.

## Verification

- `pnpm --filter @chatofy/ui test`
  → `skin-guard.spec.ts` passes with `textarea.tsx` in its scanned set
  (`SOURCES` is a directory listing of `*.tsx`, so the new file is covered
  automatically), and `root-export.spec.ts` still passes. 0 failed.
- `pnpm --filter @chatofy/ui build && pnpm --filter @chatofy/ui verify:build`
  → both exit 0.
- `node -e "import('@chatofy/ui/react').then(m => { if (typeof m.Textarea !== 'function') process.exit(1); console.log('Textarea exported'); })"`
  run from `packages/ui`
  → prints `Textarea exported`.
