## Tóm tắt yêu cầu

Xác nhận cách từng client (Web, Mobile, Extension) join meeting, thiết kế màn hình họp trong design system hiện tại.

## Câu hỏi cần trả lời

1. **Web** — SDK package nào dùng, join fit App Router và auth session như thế nào, CSP cần thêm origin nào (media + TURN)?
2. **Mobile (Expo 55 / RN 0.83)** — SDK có tương thích không, cần config plugin nào, có cần dev client không? Camera/mic/background-audio permission trên Android và iOS.
3. **Extension** — có nên đưa meeting vào scope extension không? Hiện tại extension dịch meeting bên thứ ba; khuyến nghị giữ ngoài scope hay đưa vào?
4. **Màn hình** — pre-join (kiểm tra device, chọn ngôn ngữ), in-call grid với subtitle, chat, end screen với minutes. Mỗi màn hình phải pass one-accent + two-surface budget (xem `docs/design-guidelines.md`).

## Deliverables

- Bảng SDK compatibility cho web và mobile, có nguồn dẫn.
- Mobile PoC: dev client trên một thiết bị Android thật join phòng PoC từ #207.
- Wireframes hoặc screenshot các màn hình họp, kèm accent count và surface count cho mỗi screen state.

## Acceptance criteria

- [ ] Join từ mobile hoạt động trên thiết bị thật, có ghi lại các bước tái hiện.
- [ ] Mọi màn hình chỉ dùng component đã có trong `@chatofy/ui/react` hoặc có thể thêm bằng shadcn CLI.

## Lưu ý kỹ thuật

- `mediasoup-client` trên React Native cần `react-native-webrtc` và dev build (không chạy được trên Expo Go).
- Extension (MV3) hiện dịch meeting bên thứ ba — cân nhắc kỹ trước khi mở rộng scope.
- Design rules được enforce bởi spec: `apps/web/src/design/accent-budget-app.spec.tsx` và marketing spec.
