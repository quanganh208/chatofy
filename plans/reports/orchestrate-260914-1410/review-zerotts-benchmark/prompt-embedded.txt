## What counts as a finding

Hunt specifically for:

1. **Unfair engine configuration.** Does one engine get a warm cache, a
   different device, different sample rate, different chunking, or a tuned
   parameter the other does not? Is the comparison apples-to-apples?
2. **Measurement bugs.** Time-to-first-audio and real-time-factor are easy to
   measure wrong. Check what clock starts when, whether model load or warmup
   leaks into the timed region, whether streaming and non-streaming paths are
   timed the same way, and whether the first call of a run is discarded.
3. **A scoring judge that favors one side.** The intelligibility score is an
   ASR round-trip. Check whether the ASR judge was itself trained on, or shares
   a lineage with, either engine's data; whether text normalization before WER
   silently repairs one engine's characteristic errors (diacritics, number
   reading, punctuation); and whether WER/CER is computed on the normalized or
   raw text.
4. **Sample size and variance.** How many sentences, how many seeds, how many
   voices? Is any reported difference larger than the run-to-run spread the
   seed-sensitivity script itself measured? Is a mean reported where the spread
   would change the verdict?
5. **Selection effects in the sentence sets.** Where did the VIVOS and
   conversational sentences come from, and could either set advantage one
   engine (in-domain text, sentence length, out-of-vocabulary rate)?
6. **Claims in the report unsupported by the raw JSONL.** Spot-check numbers in
   the report against results/r2/*.jsonl. Say so if a headline figure cannot be
   reconstructed from the raw rows.
7. **Tests that do not test what they appear to.** Look for assertions that
   would pass on a broken implementation.

    78	def measure_stream(engine, text: str, voice: str) -> dict:
    79	    """Time the first audio-carrying chunk, and how far the stream stays ahead.
    80	
    81	    Playback starts when the FIRST chunk lands, not when the call begins, so
    82	    what the listener has consumed by wall time `t` is `t - ttfa`. The stream has
    83	    delivered `cumulative_audio` by then. The worst value of
    84	    `(t - ttfa) - cumulative_audio` over the stream is the underrun margin:
    85	    positive anywhere means the generator fell behind the listener and the
    86	    audio stalled.
    87	
    88	    Measuring from `t0` instead would charge the stream for its own
    89	    time-to-first-audio twice and report a stall that did not happen.
    90	
    91	    A fast first chunk followed by a chunk generated slower than real time is an
    92	    audible gap that a bare TTFA figure would still report as a win, and this
    93	    repo already holds itself to the opposite standard: the app's clause
    94	    splitter records that the first part's audio outlasts the time to synthesize
    95	    the second, "so playback runs gapless".
    96	    """
    97	    sr = engine.sample_rate
    98	    t0 = time.perf_counter()
    99	    ttfa_s = None
   100	    total_samples = 0
   101	    worst_margin = float("-inf")
   102	    chunks = []
   103	
   104	    for chunk in engine.synthesize_stream(text, voice):
   105	        now = time.perf_counter() - t0
   106	        if chunk.size == 0:
   107	            continue
   108	        if ttfa_s is None:
   109	            ttfa_s = now
   110	        else:
   111	            # Just before this chunk lands: consumed vs delivered so far.
   112	            consumed_s = now - ttfa_s
   113	            delivered_s = total_samples / sr
   114	            worst_margin = max(worst_margin, consumed_s - delivered_s)
   115	        total_samples += chunk.size
   116	        chunks.append(chunk)
   117	
   118	    return {
   119	        "stream_ttfa_s": round(ttfa_s, 4) if ttfa_s is not None else None,
   120	        "stream_total_s": round(time.perf_counter() - t0, 4),
   121	        "stream_chunks": len(chunks),
   122	        "stream_underrun_margin_s": (
   123	            round(worst_margin, 4) if worst_margin != float("-inf") else None
   124	        ),
   125	        "stream_audio_s": round(total_samples / sr, 3),
   126	    }

   158	    engine.load()
   159	    load_s = time.perf_counter() - load_start
   160	
   161	    # One untimed warm-up, on the SAME voice as the timed loop — a different
   162	    # voice here would leave a per-voice initialization cost inside the first
   163	    # timed sentence.
   164	    engine.synthesize(sentences[0].text, args.voice)
   165	
   166	    f = open(out_path, "w", encoding="utf-8")
   167	    header = {
   168	        "type": "header",
   169	        "engine": args.engine,
   170	        "voice": args.voice,
   171	        "voice_slug": slug,
   172	        "gender": args.gender,
   173	        "sentence_set": set_name,
   174	        "load_s": round(load_s, 3),
   175	        # The EXPECTED count, written before the loop, so a file that ends early
   176	        # is detectably short rather than plausibly complete.
   177	        "num_sentences_expected": len(sentences),
   178	        "sample_rate": engine.sample_rate,
   179	        "supports_streaming": engine.supports_streaming and not args.no_stream,
   180	        "decode_params": engine.decode_params(),
   181	        "environment": environment_block(),
   182	    }
   183	    f.write(json.dumps(header, ensure_ascii=False) + "\n")
   184	    f.flush()
   185	
   186	    for sentence in sentences:
   187	        t0 = time.perf_counter()

   189	        proc_s = time.perf_counter() - t0
   190	        audio_s = samples.size / sr
   191	
   192	        sf.write(wav_dir / f"{sentence.id}.wav", samples, sr, subtype="PCM_16")
   193	
   194	        # What the app waits for today: the first clause only.
   195	        parts = split_into_clauses(sentence.text)
   196	        t0 = time.perf_counter()

   198	        clause_ttfa_s = time.perf_counter() - t0
   199	
   200	        n_words = len(sentence.text.split())
   201	        record = {
   202	            "type": "sentence",
   203	            "engine": args.engine,
   204	            "voice_slug": slug,
   205	            "sentence_set": set_name,
   206	            "sentence_id": sentence.id,
   207	            "text": sentence.text,
   208	            "tags": list(sentence.tags),
   209	            "n_words": n_words,
   210	            "n_clauses": len(parts),
   211	            "audio_s": round(audio_s, 3),
   212	            "proc_s": round(proc_s, 4),
   213	            "rtf": round(proc_s / audio_s, 4) if audio_s > 0 else None,
   214	            # Speaking rate. RTF is invariant to sample rate but NOT to how fast

   217	            # to listen. Recorded so the report can say whether an RTF gap is

   222	            "ttfa_whole_s": round(proc_s, 4),
   223	            "ttfa_clause_split_s": round(clause_ttfa_s, 4),
   224	        }
   225	        if engine.supports_streaming and not args.no_stream:
   226	            record.update(measure_stream(engine, sentence.text, args.voice))
   227	
   228	        f.write(json.dumps(record, ensure_ascii=False) + "\n")
   229	        f.flush()

   231	              f"{proc_s:.2f}s -> {audio_s:.1f}s audio", file=sys.stderr, flush=True)
   232	
   233	    peak_rss_mb = sampler.stop()
   234	    f.write(json.dumps({"type": "footer", "peak_rss_mb": round(peak_rss_mb, 1),
   235	                        "num_sentences_written": len(sentences)},
   236	                       ensure_ascii=False) + "\n")
   237	    f.close()
   238	    print(f"[{args.engine}/{slug}/{set_name}] wrote {out_path}", file=sys.stderr)

     1	"""Corpus WER and CER, vendored from `benchmarks/stt/stt_bench/metrics.py`.
     2	
     3	Same functions, same normalizer, so a number here sits beside the STT harness's
     4	numbers without an asterisk — which is what makes the human-speech control floors
     5	in `docs/development-journey.md` applicable to this harness at all.
     6	
     7	Added here and not in the STT copy: a paired bootstrap over sentences. The
     8	r1-versus-r2 spread is the right significance guard for latency, and a vacuous
     9	one for WER — synthesis is seeded and the ASR decodes greedily, so a second run
    10	transcribes bit-identical audio and any gap at all would read as clean
    11	separation. The real uncertainty is which sentences happen to be in the set.
    12	"""
    13	
    14	import jiwer
    15	import numpy as np
    16	
    17	from .text_normalize import normalize_text
    18	
    19	
    20	def corpus_wer(references: list[str], hypotheses: list[str]) -> float:
    21	    """Corpus-level WER over normalized ref/hyp pairs (0.0-1.0+)."""
    22	    if len(references) != len(hypotheses):
    23	        raise ValueError(f"ref/hyp count mismatch: {len(references)} vs {len(hypotheses)}")
    24	    return jiwer.wer([normalize_text(r) for r in references],
    25	                     [normalize_text(h) for h in hypotheses])
    26	
    27	
    28	def corpus_cer(references: list[str], hypotheses: list[str]) -> float:
    29	    """Corpus-level CER over normalized ref/hyp pairs (0.0-1.0+).
    30	
    31	    Reported alongside WER because Vietnamese carries meaning in diacritics that
    32	    WER cannot resolve: a hypothesis differing from its reference by one tone
    33	    mark loses the whole word to WER, exactly as an unrelated word would. CER
    34	    separates a near-miss from a miss, and is the metric to read on vi.
    35	    """
    36	    if len(references) != len(hypotheses):
    37	        raise ValueError(f"ref/hyp count mismatch: {len(references)} vs {len(hypotheses)}")
    38	    return jiwer.cer([normalize_text(r) for r in references],
    39	                     [normalize_text(h) for h in hypotheses])
    40	
    41	
    42	def sentence_errors(reference: str, hypothesis: str) -> tuple[int, int]:
    43	    """(edit distance in words, reference word count) for one pair.
    44	
    45	    Corpus WER is the ratio of the summed numerators to the summed
    46	    denominators, not the mean of per-sentence rates, so the bootstrap has to
    47	    resample these pairs rather than resampling rates.
    48	    """
    49	    ref, hyp = normalize_text(reference), normalize_text(hypothesis)
    50	    n_ref = len(ref.split())
    51	    if n_ref == 0:
    52	        return 0, 0
    53	    out = jiwer.process_words([ref], [hyp])
    54	    return out.substitutions + out.deletions + out.insertions, n_ref
    55	
    56	
    57	def paired_bootstrap_wer(
    58	    references: list[str],
    59	    hyp_a: list[str],
    60	    hyp_b: list[str],
    61	    n_resamples: int = 10_000,
    62	    seed: int = 20260914,
    63	) -> dict:
    64	    """Is A's corpus WER really below B's, or is it the sentence sample?
    65	
    66	    Paired: each resample draws the same sentence indices for both systems, so
    67	    the comparison is not contaminated by one system happening to be scored on
    68	    easier sentences than the other.
    69	
    70	    Returns the observed difference (A - B, so negative favours A), a 95%
    71	    interval on it, and the share of resamples in which A won. An interval
    72	    spanning zero is a tie, and must be reported as one.
    73	    """
    74	    if not (len(references) == len(hyp_a) == len(hyp_b)):
    75	        raise ValueError("references and both hypothesis lists must be the same length")
    76	
    77	    pairs_a = np.array([sentence_errors(r, h) for r, h in zip(references, hyp_a)], dtype=float)
    78	    pairs_b = np.array([sentence_errors(r, h) for r, h in zip(references, hyp_b)], dtype=float)
    79	
    80	    def wer_of(pairs, idx):
    81	        denom = pairs[idx, 1].sum()
    82	        return float(pairs[idx, 0].sum() / denom) if denom else float("nan")
    83	
    84	    all_idx = np.arange(len(references))
    85	    observed = wer_of(pairs_a, all_idx) - wer_of(pairs_b, all_idx)
    86	
    87	    rng = np.random.default_rng(seed)
    88	    diffs = np.empty(n_resamples)
    89	    for i in range(n_resamples):
    90	        idx = rng.integers(0, len(references), len(references))
    91	        diffs[i] = wer_of(pairs_a, idx) - wer_of(pairs_b, idx)
    92	
    93	    lo, hi = np.percentile(diffs, [2.5, 97.5])
    94	    return {
    95	        "observed_diff": observed,
    96	        "ci95_low": float(lo),
    97	        "ci95_high": float(hi),
    98	        "p_a_better": float((diffs < 0).mean()),
    99	        "separates": bool(lo > 0 or hi < 0),
   100	        "n_sentences": len(references),
   101	        "n_resamples": n_resamples,
   102	    }
   103	
   104	
   105	def win_loss_tie(references: list[str], hyp_a: list[str], hyp_b: list[str]) -> dict:
   106	    """Per-sentence outcome counts — the cheap companion to the bootstrap."""
   107	    wins = losses = ties = 0
   108	    for ref, a, b in zip(references, hyp_a, hyp_b):
   109	        ea, na = sentence_errors(ref, a)
   110	        eb, _ = sentence_errors(ref, b)
   111	        if na == 0:
   112	            continue
   113	        if ea < eb:
   114	            wins += 1
   115	        elif ea > eb:
   116	            losses += 1
   117	        else:
   118	            ties += 1
   119	    return {"a_wins": wins, "b_wins": losses, "ties": ties}

     1	"""Shared text normalization applied to references AND hypotheses before WER.
     2	
     3	VERBATIM COPY of `benchmarks/stt/stt_bench/text_normalize.py`. Do not edit it
     4	here. The human-speech control floors this harness quotes — PhoWhisper-vi 7.71%
     5	and Zipformer-vi 5.38% over the same 50 VIVOS utterances — were produced by that
     6	file. Diverging from it silently invalidates the comparison those floors exist to
     7	enable, which is the one coupling the "benchmark projects stay independent"
     8	convention does not cover. If the STT harness's copy changes, re-copy it and
     9	re-derive the floors.
    10	
    11	Every engine's output goes through the exact same pipeline so WER differences
    12	reflect the models, not formatting conventions. Vietnamese diacritics are
    13	preserved (only casing/punctuation/whitespace are normalized); numbers are left
    14	as written — a known WER caveat recorded in the results report.
    15	"""
    16	
    17	import re
    18	import unicodedata
    19	
    20	# \w with re.UNICODE keeps Vietnamese letters and digits; everything else
    21	# (punctuation, symbols) becomes a space so word boundaries survive.
    22	_NON_WORD_RE = re.compile(r"[^\w\s]", re.UNICODE)
    23	_UNDERSCORE_RE = re.compile(r"_")
    24	_WHITESPACE_RE = re.compile(r"\s+")
    25	
    26	
    27	def normalize_text(text: str) -> str:
    28	    """Normalize a transcript for WER comparison.
    29	
    30	    Steps: Unicode NFC (composes Vietnamese diacritics consistently across
    31	    engines), lowercase, strip punctuation/symbols, collapse whitespace.
    32	    """
    33	    text = unicodedata.normalize("NFC", text)
    34	    text = text.lower()
    35	    text = _NON_WORD_RE.sub(" ", text)
    36	    # \w matches underscore; treat it as punctuation, not a word character.
    37	    text = _UNDERSCORE_RE.sub(" ", text)
    38	    text = _WHITESPACE_RE.sub(" ", text)
    39	    return text.strip()

    51	class PeakRssSampler:
    52	    """Samples process-tree RSS in a background thread, records the peak."""
    53	
    54	    def __init__(self, pid: int | None = None, interval_s: float = 0.1):
    55	        self._process = psutil.Process(pid)
    56	        self._interval_s = interval_s
    57	        self._peak_bytes = 0
    58	        self._stop_event = threading.Event()
    59	        self._thread = threading.Thread(target=self._sample_loop, daemon=True)
    60	
    61	    def _tree_rss(self) -> int:
    62	        total = 0
    63	        try:
    64	            total = self._process.memory_info().rss
    65	            for child in self._process.children(recursive=True):
    66	                try:
    67	                    total += child.memory_info().rss
    68	                except psutil.NoSuchProcess:
    69	                    continue
    70	        except psutil.NoSuchProcess:
    71	            pass
    72	        return total
    73	
    74	    def _sample_loop(self) -> None:
    75	        while not self._stop_event.is_set():
    76	            self._peak_bytes = max(self._peak_bytes, self._tree_rss())
    77	            time.sleep(self._interval_s)
    78	
    79	    def start(self) -> "PeakRssSampler":
    80	        self._peak_bytes = self._tree_rss()

    86	        self._stop_event.set()

    88	        self._peak_bytes = max(self._peak_bytes, self._tree_rss())

    97	    against. They differ only where the set was built from a corpus whose
    98	    reference casing is not what we want to feed an engine — VIVOS is ALL CAPS.

   101	    id: str
   102	    text: str
   103	    ref_text: str
   104	    tags: tuple[str, ...]

   107	def load_sentences(path: Path) -> list[Sentence]:
   108	    """Load a JSONL sentence set, taking each row's declared `id`.
   109	
   110	    Blank lines and `#` comment lines are skipped, so a set can carry its policy
   111	    header in the file itself rather than only in the plan.
   112	    """
   113	    sentences: list[Sentence] = []
   114	    seen: set[str] = set()

   117	            line = line.strip()

   126	                raise ValueError(f"{path}:{lineno}: empty text or ref_text for {sid!r}")

   129	                    id=sid,
   130	                    text=row["text"],
   131	                    ref_text=row["ref_text"],
   132	                    tags=tuple(row.get("tags", ())),
   133	                )
   134	            )

   136	        raise ValueError(f"no sentences in {path}")

########## FILE: benchmarks/tts-vi/tts_vi_bench/clause_split.py ##########
     1	"""Port of the app's clause splitter, so the incumbent is timed as it ships.
     2	
     3	`apps/api/src/modules/translate/audio/clause-splitter.ts` splits translated text
     4	at clause boundaries *in front of* the engine, purely to cut time-to-first-audio.
     5	Its header records the measured effect: 0.648s -> 0.340s, 0.907s -> 0.393s,
     6	1.061s -> 0.813s.
     7	
     8	That makes it load-bearing for this benchmark. VieNeu has no streaming API, so
     9	the naive comparison is ZeroTTS's first streamed chunk against VieNeu's whole
    10	sentence — but the app never waits for a whole sentence. Timing it that way
    11	would overstate the incumbent roughly twofold and hand ZeroTTS a win it did not
    12	earn. The number the verdict has to beat is VieNeu *clause-split*, and producing
    13	it requires the same split the app performs.
    14	
    15	Ported rather than shared because the original is TypeScript inside the API and
    16	this is a standalone Python harness. `tests/test_clause_split.py` checks the
    17	cases the original's own comments call out, so a divergence surfaces as a failing
    18	test rather than as a quietly different number.
    19	"""
    20	
    21	import re
    22	
    23	#: Shortest part worth its own synthesis call. Deliberately small: the original
    24	#: records that the measured win came from leading clauses as short as "Hello,"
    25	#: (6 chars) and "Xin chào," (9), so a larger floor would merge exactly the
    26	#: split that pays. It exists only to absorb sub-word fragments like the "Mr."
    27	#: in "Mr. Smith".
    28	MIN_PART_CHARS = 4
    29	
    30	#: Clause and sentence terminators, kept with the text they follow so the engine
    31	#: still sees the punctuation it takes intonation from. The trailing lookahead
    32	#: is load-bearing: requiring whitespace or end-of-text after the mark keeps
    33	#: "3.5" and the Vietnamese decimal comma in "1,5 triệu" from reading as
    34	#: boundaries.
    35	BOUNDARY = re.compile(r"[,;:.!?…]+(?=\s|$)")
    36	
    37	
    38	def split_into_clauses(text: str) -> list[str]:
    39	    """Break text into clause-level synthesis units.
    40	
    41	    Returns a single part when there is no usable boundary, and an empty list
    42	    for blank input — matching the original's documented contract.
    43	    """
    44	    trimmed = text.strip()
    45	    if not trimmed:
    46	        return []
    47	
    48	    parts: list[str] = []
    49	    start = 0
    50	    for match in BOUNDARY.finditer(trimmed):
    51	        end = match.end()
    52	        part = trimmed[start:end].strip()
    53	        if part:
    54	            parts.append(part)
    55	        start = end
    56	
    57	    tail = trimmed[start:].strip()
    58	    if tail:
    59	        parts.append(tail)
    60	
    61	    return _absorb_fragments(parts)
    62	
    63	
    64	def _absorb_fragments(parts: list[str]) -> list[str]:
    65	    """Fold parts too short to stand on their own into their neighbour."""
    66	    merged: list[str] = []
    67	    for part in parts:
    68	        previous = merged[-1] if merged else None
    69	        too_short = len(part) < MIN_PART_CHARS
    70	        previous_too_short = previous is not None and len(previous) < MIN_PART_CHARS
    71	        if previous is not None and (too_short or previous_too_short):
    72	            merged[-1] = f"{previous} {part}"
    73	        else:
    74	            merged.append(part)
    75	    return merged

     1	"""TtsEngine base — the contract every benchmarked Vietnamese TTS engine implements.
     2	
     3	Two additions over the English harness's version, each forced by what this
     4	comparison has to measure:
     5	
     6	- `synthesize` takes a **voice**, because each engine is measured on two of them
     7	  rather than on one fixed speaker.
     8	- `synthesize_stream` exists at all, because one engine streams and the other
     9	  does not, and time-to-first-audio is the metric most likely to decide the
    10	  result. The base declares streaming unsupported so the engine that lacks it
    11	  says so by inheriting rather than by raising.
    12	"""
    13	
    14	from abc import ABC, abstractmethod
    15	from collections.abc import Iterator
    16	
    17	import numpy as np
    18	
    19	
    20	class TtsEngine(ABC):
    21	    """One benchmarked Vietnamese TTS engine, at one voice."""
    22	
    23	    engine_id: str
    24	    #: gender -> voice token. The pair each engine speaks with by default, which
    25	    #: is what `services/local-tts` exposes to callers through `POST /synthesize`.
    26	    VOICES: dict[str, str]
    27	    #: Whether `synthesize_stream` is real. False here; overridden where true.
    28	    supports_streaming: bool = False
    29	
    30	    @abstractmethod
    31	    def load(self) -> None:
    32	        """Load model weights. Timed separately from synthesis."""
    33	
    34	    @abstractmethod
    35	    def synthesize(self, text: str, voice: str) -> tuple[np.ndarray, int]:
    36	        """Synthesize one sentence → (float32 samples in [-1, 1], sample_rate)."""
    37	
    38	    def synthesize_stream(self, text: str, voice: str) -> Iterator[np.ndarray]:
    39	        """Yield audio chunks as they are generated.
    40	
    41	        The default is not a stub that returns nothing — it raises, so a caller
    42	        that reaches it has a bug rather than a silently empty measurement.
    43	        Check `supports_streaming` first.
    44	        """
    45	        raise NotImplementedError(f"{self.engine_id} does not stream")
    46	
    47	    @abstractmethod
    48	    def decode_params(self) -> dict:
    49	        """Everything needed to reproduce this run, recorded in the result header.
    50	
    51	        For a stochastic engine this includes the seed and every sampling
    52	        parameter: without them a recorded number cannot be reproduced even on
    53	        the same machine with the same weights.
    54	        """

########## FILE: benchmarks/tts-vi/tts_vi_bench/engines/zerotts_vi.py ##########
     1	"""Vietnamese TTS — ZeroTTS (fp32 ONNX, CPU, torch-free).
     2	
     3	Every constructor argument below overrides a package default that would
     4	otherwise bias this benchmark. They are set explicitly, and the reasons are
     5	recorded here rather than in a commit message, because each one is invisible in
     6	the output it corrupts.
     7	
     8	**Threads.** `ZeroTTS.__init__` defaults `intra_op_num_threads=4`
     9	(`synthesizer.py`), where VieNeu is constructed with 8. Left alone the
    10	challenger runs on half the CPU of the incumbent and nothing in the result says
    11	so. `codec_intra_op_num_threads` is a second, separate knob — the codec decoder
    12	is its own session and the streaming path's cost lives there — so both are set
    13	and both are recorded.
    14	
    15	**Warm-up.** `__init__` defaults `warmup=True` and pushes a dummy request
    16	through every hot-path session during construction. That lands inside the timed
    17	`load()`, which VieNeu has no equivalent of, and the harness then runs its own
    18	untimed warm-up sentence on top — so ZeroTTS would warm twice and VieNeu once.
    19	Constructed with `warmup=False`; the harness's warm-up serves both engines
    20	identically.
    21	
    22	**Seeding.** The model draws from the *global* `np.random` on every generated
    23	frame and exposes no seed parameter. Unseeded, every latency, RTF, TTFA and WER
    24	figure is one draw from a distribution rather than a measurement. Seeded
    25	immediately before each synthesis, and the seed is recorded.
    26	
    27	Seeding is necessary but not sufficient for bit-reproducibility: the sampling
    28	happens *inside* the ONNX graph against fp32 logits, and top-k/top-p over an
    29	autoregressive loop turns a one-ULP difference into a divergent utterance. So
    30	the thread count and the `onnxruntime` version are pinned too, and results are
    31	claimed only at the recorded seed, threads and runtime.

    97	        before the first `next()`, and `decode_params` records that it was.

    99	        stream = self._tts.synthesize_stream(text, voice=voice)
   100	        np.random.seed(SEED)
   101	        for chunk in stream:
   102	            yield np.asarray(chunk, dtype=np.float32).reshape(-1)

   104	    @property
   105	    def sample_rate(self) -> int:
   106	        return self._tts.sample_rate

########## FILE: benchmarks/tts-vi/scripts/seed_sensitivity.py ##########

     8	  which is what makes the main run reproducible, but it also means the headline
     9	  WER is ONE draw from a distribution. A different seed is a different draw.

    11	  across the two tags), so it has a spread of its own with no knob to set.

    14	property of the engines and no verdict can rest on it. This script measures both
    15	spreads so they can be set beside the gap.

    17	Writes to `results/seed-sensitivity/`; touches nothing the main run produced.
    18

    21	"""

    24	import json
    25	import sys

    29	import soundfile as sf

    31	sys.path.insert(0, str(Path(__file__).resolve().parent.parent))

    33	from tts_vi_bench.asr_judges import PhoWhisperJudge  # noqa: E402

    40	OUT_DIR = BENCH_ROOT / "results" / "seed-sensitivity"

    43	def main() -> int:
    44	    parser = argparse.ArgumentParser(description=__doc__)
    45	    parser.add_argument("--engine", default="zerotts-vi",
    46	                        choices=["zerotts-vi", "vieneu-vi"])
    47	    parser.add_argument("--voice", default="baotrang")
    48	    parser.add_argument("--seeds", default="11,22,33",
    49	                        help="zerotts only: one pass per seed")
    50	    parser.add_argument("--runs", type=int, default=None,
    51	                        help="vieneu only: repeat N times (it has no seed knob)")
    52	    parser.add_argument(
    53	        "--sentences", type=Path,
    54	        default=BENCH_ROOT / "data" / "sentences-conversational.jsonl")
    55	    args = parser.parse_args()
    56	
    57	    sentences = load_sentences(args.sentences)
    58	    is_zero = args.engine == "zerotts-vi"
    59	    # ZeroTTS varies by seed; VieNeu varies on its own, so its "passes" are bare
    60	    # repeats and the label is the repeat index rather than a seed.
    61	    passes = ([int(s) for s in args.seeds.split(",")] if is_zero
    62	              else list(range(1, (args.runs or 6) + 1)))
    63	
    64	    engine = ZeroTtsVi() if is_zero else VieNeuVi()
    65	    engine.load()
    66	    judge = PhoWhisperJudge()
    67	    judge.load()
    68	
    69	    rows = []
    70	    for label in passes:
    71	        wav_dir = OUT_DIR / args.engine / f"pass-{label}" / args.voice.replace(" ", "-")
    72	        wav_dir.mkdir(parents=True, exist_ok=True)
    73	        hyps, refs = [], []
    74	        for s in sentences:
    75	            # Override the module-level seed for this pass only. Seeding here
    76	            # rather than inside the engine keeps the engine's recorded
    77	            # decode_params honest about what the MAIN run used.
    78	            if is_zero:
    79	                np.random.seed(label)
    80	                samples = engine._tts.synthesize(s.text, voice=args.voice)
    81	                samples = np.asarray(samples, dtype=np.float32).reshape(-1)
    82	            else:
    83	                samples, _sr = engine.synthesize(s.text, args.voice)
    84	            path = wav_dir / f"{s.id}.wav"
    85	            sf.write(path, samples, engine.sample_rate, subtype="PCM_16")
    86	            hyps.append(judge.transcribe(path))
    87	            refs.append(s.ref_text)
    88	        wer, cer = corpus_wer(refs, hyps), corpus_cer(refs, hyps)
    89	        rows.append({"pass": label, "engine": args.engine, "voice": args.voice,
    90	                     "wer": wer, "cer": cer, "n": len(sentences)})
    91	        kind = "seed" if is_zero else "repeat"
    92	        print(f"{kind} {label}: WER {wer*100:.2f}%  CER {cer*100:.2f}%", flush=True)
    93	
    94	    wers = [r["wer"] for r in rows]
    95	    spread = max(wers) - min(wers)
    96	    summary = {
    97	        "engine": args.engine,
    98	        "voice": args.voice,
    99	        "sentence_set": args.sentences.stem,
   100	        "judge": judge.judge_id,
   101	        "runs": rows,
   102	        "wer_spread_pp": spread * 100,
   103	        "note": (
   104	            "Compare wer_spread_pp against the ZeroTTS-minus-VieNeu gap in "
   105	            "results/<tag>/intelligibility-summary.json. A spread of the same "
   106	            "order as the gap means the gap is not a property of the engines "
   107	            "and no verdict can rest on it."
   108	        ),
   109	    }
   110	    OUT_DIR.mkdir(parents=True, exist_ok=True)
   111	    (OUT_DIR / "summary.json").write_text(
   112	        json.dumps(summary, ensure_ascii=False, indent=2), encoding="utf-8")
   113	    mean = sum(wers) / len(wers)
   114	    print(f"\n{args.engine}/{args.voice}: mean WER {mean*100:.2f}%  "
   115	          f"range {min(wers)*100:.2f}-{max(wers)*100:.2f}%  spread {spread*100:.2f}pp")
   116	    print(f"[done] {OUT_DIR / 'summary.json'}")
   117	    return 0

   121	    sys.exit(main())

########## FILE: benchmarks/tts-vi/scripts/build_vivos_set.py ##########
     1	"""Emit the VIVOS comparability arm from the STT harness's manifest.
     2	
     3	Reads `benchmarks/stt/data/manifest-vi.jsonl` and never writes to it.
     4	
     5	Two things this script decides, both of which the report has to state:
     6	
     7	**Casing.** VIVOS references are ALL CAPS. ZeroTTS processes raw orthography
     8	with no grapheme-to-phoneme stage, so casing can reach the model — feeding it
     9	shouted text would measure something no caller produces. So `text` is
    10	sentence-cased for synthesis while `ref_text` keeps the corpus's original caps,
    11	and the scorer's normalizer (which lowercases both sides) reconciles them.
    12	
    13	**Why this arm is secondary.** ZeroBench-TTS redistributes VIVOS, so ZeroTTS may
    14	have seen this material. It is here for comparability with the existing STT
    15	numbers, which were measured on these exact 50 utterances; the conversational
    16	arm is the one the verdict rests on.
    17	"""
    18	
    19	import json
    20	import sys
    21	from pathlib import Path
    22	
    23	BENCH_ROOT = Path(__file__).resolve().parent.parent
    24	SOURCE = BENCH_ROOT.parent / "stt" / "data" / "manifest-vi.jsonl"
    25	OUT = BENCH_ROOT / "data" / "sentences-vivos.jsonl"
    26	
    27	HEADER = """\
    28	# VIVOS — the comparability arm. Built by scripts/build_vivos_set.py; do not edit.
    29	#
    30	# Source: benchmarks/stt/data/manifest-vi.jsonl (read-only), the same 50
    31	# utterances the STT harness measured, which is what makes the human-speech
    32	# control floors in docs/development-journey.md apply here.
    33	#
    34	# CASING: `ref_text` keeps the corpus's ALL CAPS; `text` is sentence-cased for
    35	# synthesis, because ZeroTTS reads raw orthography with no G2P stage and no
    36	# caller ever sends shouted text. The scorer's normalizer lowercases both sides.
    37	#
    38	# CAVEAT: ZeroBench-TTS redistributes VIVOS, so ZeroTTS may have seen this
    39	# material. Secondary to the conversational arm for exactly that reason.
    40	"""
    41	
    42	
    43	def sentence_case(text: str) -> str:
    44	    """ALL CAPS -> sentence case, leaving Vietnamese diacritics untouched.
    45	
    46	    `str.capitalize()` would be wrong: it lowercases the rest of the string but
    47	    also strips any legitimate internal capital. These references carry no
    48	    proper-noun casing to preserve (they are uniformly upper), so lowering the
    49	    tail and raising the first character is exact here.
    50	    """
    51	    text = text.strip().lower()
    52	    return text[:1].upper() + text[1:] if text else text
    53	
    54	
    55	def main() -> int:
    56	    if not SOURCE.exists():
    57	        print(f"[error] missing source manifest {SOURCE}", file=sys.stderr)
    58	        return 1
    59	
    60	    rows = []
    61	    for line in SOURCE.read_text(encoding="utf-8").splitlines():
    62	        line = line.strip()
    63	        if not line:
    64	            continue
    65	        src = json.loads(line)
    66	        ref = src["ref_text"].strip()
    67	        rows.append(
    68	            {
    69	                # Prefixed so it cannot collide with a conversational id inside
    70	                # the shared results tree.
    71	                "id": f"vivos-{src['id']}",
    72	                "text": sentence_case(ref),
    73	                "ref_text": ref,
    74	                "tags": ["vivos"],
    75	            }
    76	        )
    77	
    78	    OUT.write_text(
    79	        HEADER + "\n".join(json.dumps(r, ensure_ascii=False) for r in rows) + "\n",
    80	        encoding="utf-8",
    81	    )
    82	    print(f"[done] {len(rows)} rows -> {OUT.relative_to(BENCH_ROOT)}")
    83	    return 0
    84	
    85	
    86	if __name__ == "__main__":
    87	    sys.exit(main())

# Conversational Vietnamese — the register the app actually emits.
#
# These are the shape of Gemini's Vietnamese translations of conversational
# English: asking prices, ordering, directions, booking, apologising. Every row
# carries at least one clause boundary where it is natural, because the TTFA
# arms split on the app's own rule and a set of boundary-free sentences would
# measure clause splitting doing nothing.
#
# ORTHOGRAPHY POLICY — load-bearing, enforced by the build check:
#   `text` spells every numeral, time and currency amount out in Vietnamese
#   words and contains no abbreviations. The round-trip scores an ASR transcript
#   against this string, and the shared normalizer leaves numbers as written by
