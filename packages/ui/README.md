# @chatofy/ui

Reserved for shared UI primitives once patterns emerge across web/mobile. Add only when duplication becomes painful (YAGNI).

## When to add components

- Same visual component needed in both `apps/web` and `apps/mobile`
- Pattern has stabilized (not actively changing)
- Component has no app-specific business logic

## Current state

Empty. Each app maintains its own UI until cross-app reuse is clearly warranted.
